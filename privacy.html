Privacy policy

ParcelBar · last updated November 2026

Who uses it

ParcelBar is a personal desktop application used only by its developer, on the developer's own computers, with the developer's own Gmail account. It has no other users.

What Google data it accesses

With the https://www.googleapis.com/auth/gmail.readonly scope, ParcelBar searches the connected Gmail account for shipping-notification emails from the last 60 days and reads them to extract: carrier, tracking number, order number, store name, item summary, delivery status, and expected delivery date.

How the data is used and stored

  • Email content is processed in memory on the user's computer and is not written to disk or logs.
  • Only the extracted package details listed above are stored, in a local file on that computer.
  • The OAuth refresh token is stored in the operating system's keychain (macOS Keychain or Windows Credential Manager).
  • ParcelBar has no servers. No data is sent anywhere except to Google's APIs to read the mail.
  • Data is not sold, shared, transferred to third parties, used for advertising, or used to train AI or ML models.

Limited Use

ParcelBar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revocation

Choosing "Disconnect & revoke" in ParcelBar deletes the stored token and revokes it with Google. Access can also be removed at myaccount.google.com/permissions. Deleting the ParcelBar data folder removes all stored package details.
